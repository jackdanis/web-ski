Web Ski

Skiing game prototypes for desktop and mobile browsers.

  • Endless SkierEndless downhill run in a Line Rider style. Jump, backflip, dodge rocks, land clean.
  • Downhill 3DThird-person 3D endless run. Carve through trees, hit kickers, spin and flip, stick the landing.
  • Golden SkiArcade golf presentation on a ski run. Flick to push off, read the lie, hole out through the finish gate in as few pushes as you can.
